# Contributing

Contributions are welcome when they preserve reproducibility and the interpretation boundary.

1. Create a focused branch.
2. Run `make quality`.
3. Run `make sql-test` with Docker.
4. Add tests for parser, schema, or analytical changes.
5. Explain any change to metric meaning or data lineage in the pull request.

Never add claims that a fails-to-deliver observation proves short selling, naked short selling, manipulation, or misconduct. Do not commit downloaded raw archives.
